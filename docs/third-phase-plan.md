## schema／JSON v3 契約

SQLite v3 增加 bookmarks（每本最多 200、名稱 1–80 字、筆記最多 2000 字、頁名與原索引）及本機備份偏好／狀態。升級已存在的 v1／v2 前，以 SQLite online backup API 一致性保存所有原表、WAL 資料，再以交易升級；失敗原 schema 保持，安全快照保留。新空庫不需要升級前快照。

JSON v3 含 v2 metadata 與書籤；v1／v2 仍可讀，舊備份沒有書籤。以來源與舊 ID 映射新加入書籍的書籤，既有來源連書籤一起略過、不覆寫。未知版本與無效關聯整批拒絕，實際還原重新解析。備份不含漫畫、封面、外觀／工具列與本機自動備份偏好。

自動备份預設關閉，可設定保留 1–20 份；啟動及每 15 分鐘檢查，一天最多自動成功一份，另可手動立即建立。所有成功時間／錯誤有文字顯示。僅清理本程式備份目錄內、檔名符合嚴格規則且內容可識別的自動 JSON；升級快照與未知檔案不清理。匯出與快照 create_new 防覆寫，失敗僅清除本次不完整檔案。

下一集限定同一系列所有集數可辨識且不重複；接受正整數／0，全形數字在 UI NFKC 解析，缺值、非數字／特殊集數或重複均要求手動選書，數字跳號也明確提示。失效來源不跳過，最後跨頁組顯示按鈕，切換先 flushProgress，開書失敗保留目前 reader。
